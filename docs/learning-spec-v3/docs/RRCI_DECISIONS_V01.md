# RRCI scientific decisions frozen for V0.1

Date: 2026-09-24

1. **Activation nuance**: Explorer receives precise everyday rules without teaching activation exceptions. Scientist includes the exception: suitable radiation/particle type and energy may induce nuclear activation.
2. **Explorer decay mechanisms**: include only the basic mechanism:
   - alpha = 2p + 2n emitted;
   - beta- = neutron -> proton + emitted electron (neutrino detail omitted);
   - beta+ = proton -> neutron + emitted positron (neutrino detail omitted);
   - EC = atomic electron captured, proton -> neutron (neutrino/atomic relaxation detail omitted).
3. **Question information value**: research/process metric from gameplay only, not a conceptual pre/post outcome.
4. **Scientist therapy item**: retain qualitative alpha vs beta- comparison (alpha typically higher LET/shorter range; beta- lower LET/longer range).
5. **Breadth coding**: keep `environment` and `natural radioactivity` as distinct categories.
6. **Practical Explorer irradiation examples**: approved food irradiation and external exposure near a PET patient must be used to distinguish exposure from becoming radioactive/contaminated.
