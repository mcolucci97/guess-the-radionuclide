# BOZZA — Informazione per genitori/tutori e autorizzazione, se richiesta dal protocollo

**NON USARE SENZA VALIDAZIONE INFN/DPO.**

INFN sta valutando un gioco educativo dedicato ai radionuclidi e alla radioattività. Lo scopo è capire se una sessione di gioco può favorire la comprensione di concetti scientifici e delle applicazioni della radioattività.

La sessione può comprendere un breve questionario iniziale, una partita e un breve questionario finale.

Dati previsti: fascia di età e formazione, risposte ai test, eventi di gioco, tempi/interventi didattici. Il dataset non è progettato per contenere nome, cognome o data di nascita completa.

La partecipazione alla ricerca è volontaria. Il ragazzo/la ragazza deve poter esprimere il proprio assenso secondo il protocollo.
