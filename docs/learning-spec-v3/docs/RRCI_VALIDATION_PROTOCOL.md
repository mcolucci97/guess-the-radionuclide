# RRCI validation protocol

## Status

This protocol converts the V0 item bank into a research instrument. Do not call the RRCI "validated" until these stages are completed.

## 1. Construct and blueprint

Freeze the intended score interpretations before piloting:

### Primary Explorer constructs
1. conceptual understanding of radioactivity;
2. transfer/application;

### Key secondary constructs
- misconception status;
- breadth of applications/contexts;
- risk-context reasoning;
- scientific-questioning competence.

The Scientist extension is scored separately and must not be required for an Explorer score.

## 2. Expert content review

Recommended panel: **6–10 reviewers** with complementary expertise, ideally including:
- nuclear/radiation physics;
- nuclear medicine / medical physics or radiopharmacy;
- radiation protection / environmental radioactivity;
- physics/science education research;
- upper-secondary science teaching;
- science communication/outreach.

Each reviewer rates every item independently on 4-point scales:
- scientific accuracy;
- relevance to the stated concept;
- clarity;
- age/level appropriateness;
- diagnostic value of distractors;
- absence of avoidable ambiguity.

For relevance/clarity calculate I-CVI. With 6–10 experts, `I-CVI >= 0.78` is a useful conventional threshold for retaining an item without major concern; use qualitative comments as equally important evidence. Report which S-CVI method is used if a scale-level index is reported.

Automatic rule proposed for V0 triage:
- I-CVI >= .78 and no scientific objection -> retain/revise minor;
- .70–.77 -> mandatory revision;
- < .70 or any unresolved scientific objection -> remove/rewrite;
- never retain a scientifically ambiguous item merely because the numerical CVI is high.

## 3. Cognitive interviews / response-process validity

Run think-aloud/cognitive interviews **after expert revision and before large pilot**.

Suggested purposive sample:
- Explorer: 10–15 people spanning 14–17 and non-specialist adults;
- Scientist: 6–10 STEM university/professional participants.

For each item ask, without teaching:
1. "Cosa ti sta chiedendo questa domanda?"
2. "Come hai deciso la risposta?"
3. "Che cosa significa per te [key term]?"
4. "Perché le altre opzioni non ti convincono?"
5. confidence: low / medium / high.

Record whether:
- intended construct was used;
- wording was misread;
- a distractor attracted the intended misconception;
- correct choice was reached through an unintended shortcut;
- scientific vocabulary is age-appropriate.

Do not use these interviews to train participants before recording their initial reasoning.

## 4. Pilot

First quantitative pilot target: **~100–150 Explorer responses** if logistically feasible.

For each item inspect:
- proportion correct (CTT difficulty/facility);
- point-biserial or upper/lower discrimination;
- distractor frequencies and distractor discrimination;
- missing/timeout rate;
- completion time;
- subgroup anomalies;
- item-total relationship within the relevant construct, not blindly against a heterogeneous total.

Useful screening heuristics, not immutable laws:
- most retained items should have proportion correct roughly 0.20–0.80;
- discrimination around >0.30 is desirable for many items;
- distractors chosen by <5% are candidates for revision/removal;
- a distractor attracting high performers more than low performers requires investigation.

The RRCI is intentionally multidimensional. Do **not** delete conceptually essential items solely to maximize Cronbach alpha.

## 5. Parallel forms

Develop Form A and Form B from the calibrated bank, using the same blueprint.

Recommended final Explorer test target:
- ~15 scored structured items;
- 1 open breadth item;
- ~8–10 minutes.

Counterbalance forms in the main pre/post study:
- half: A pre -> B post;
- half: B pre -> A post.

Use a small number of common anchor items only after confirming they do not dominate pretest sensitization. Parallelism/equivalence must be checked empirically; conceptual pairing alone is not evidence that two items are equivalent.

## 6. Delayed form

At 7–14 days, use a shorter alternate form (~6–8 structured items + optional breadth item), emphasizing:
- core concepts;
- transfer;
- misconceptions previously targeted.

Do not simply repeat the immediate post-test verbatim.

## 7. Larger psychometric validation

When several hundred responses are available:
- re-check CTT metrics across subgroups;
- evaluate dimensionality consistent with the construct map;
- consider Rasch/IRT only when sample size and model fit justify it;
- inspect differential item functioning by relevant groups (e.g. age band / education), avoiding overinterpretation of small cells;
- evaluate alternate-form equivalence.

## 8. Outcome scoring

Do not reduce all data to one percentage.

Report separately:
- `ConceptualCoreScore`;
- `TransferScore`;
- misconception transitions per misconception;
- `BreadthScore` and category profile;
- optional risk-context score;
- process measures from gameplay.

Scientist extension score remains separate.

## 9. Research-design protection

The test item bank and Learning Engine content must be separate in code. The game must never deliberately teach a test item's wording/answer.

Pretest sensitization is a real methodological concern in educational interventions. Parallel forms/counterbalancing are the default practical mitigation; a Solomon four-group design is an optional later methodological study if the sample is large enough.
