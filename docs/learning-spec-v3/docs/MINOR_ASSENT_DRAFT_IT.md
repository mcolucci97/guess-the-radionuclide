**Da validare con INFN/DPO.**

## Vuoi partecipare allo studio?

Stiamo studiando se *Indovina il Radionuclide* aiuta a capire meglio la radioattività e i suoi usi.

Se partecipi:
- farai un breve test prima del gioco;
- giocherai una partita;
- farai un breve test dopo;
- alcune azioni della partita saranno registrate per la ricerca.

I dati saranno associati a un codice e analizzati per lo studio. Non devi scrivere il tuo nome nelle risposte.

Partecipare è una tua scelta. Puoi dire di no.
