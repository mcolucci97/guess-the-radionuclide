# RRCI Expert Review Packet V0.1

## Purpose

This packet is for scientific/content validation before student cognitive interviews. It is **not** a request to judge whether the game is enjoyable.

## Reviewer task

For each assigned item, rate:
1. scientific accuracy (1–4);
2. relevance to intended construct (1–4);
3. clarity (1–4);
4. appropriateness for Explorer/Scientist (1–4);
5. distractor diagnosticity (1–4);
6. whether more than one answer is defensible (yes/no);
7. recommendation: retain / minor revision / major revision / remove.

Any scientific inaccuracy overrides a favorable numerical CVI.

## Specific checks requested in V0.1

- Explorer E10: verify that the food-irradiation and PET-exposure wording distinguishes exposure from contamination without implying that nuclear activation is impossible in all circumstances.
- Explorer E18–E21: verify that the basic decay mechanisms are accurate but age-appropriate; omission of neutrino details is intentional.
- Scientist S11: PET annihilation mechanism.
- Scientist S12: qualitative alpha vs beta-minus range/LET comparison.
- Scientist S13: activation nuance and boundary between ordinary irradiation and activation-producing nuclear reactions.
- E40: verify breadth categories do not encode a pro/anti-nuclear attitude.

## Construct-level questions

- Is any essential radioactivity concept missing?
- Is medicine overrepresented relative to the stated broader outreach objective?
- Are any risk items persuasive rather than scientifically diagnostic?
- Are Explorer items comprehensible to a 14-year-old without prior nuclear physics?
- Do Scientist items test deeper understanding rather than trivia?
