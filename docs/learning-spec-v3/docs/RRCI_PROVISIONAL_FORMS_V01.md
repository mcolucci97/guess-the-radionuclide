## Why these are only candidates

A and B currently differ in exact content and likely difficulty. The goal of the pilot item bank is to learn which items can form approximately equivalent families.

The final forms should satisfy:
- same construct weights;
- comparable difficulty distribution;
- comparable transfer proportion;
- comparable misconception coverage;
- similar completion time;
- no form systematically advantaging one educational subgroup.

## Scientist extension candidate

The Scientist extension can initially be administered as a single 13-item pilot bank (S01–S13). After calibration, create shorter alternate subsets only if repeated Scientist testing is required.
