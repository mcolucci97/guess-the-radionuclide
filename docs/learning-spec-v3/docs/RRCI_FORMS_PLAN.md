# RRCI provisional forms plan

**Do not deploy these as final forms before expert review/cognitive interviews/pilot.**

## Blueprint target for each final Explorer form

| Domain | Target items |
|---|---:|
| radioactivity / natural-artificial / risk context | 3 |
| isotope / nuclear identity | 1 |
| half-life | 2 |
| decay & radiation distinction | 3 |
| PET / SPECT / therapy & application transfer | 4 |
| broader applications | 1 |
| scientific questioning | 1 |
| **Total structured** | **15** |
| open breadth | **1** |

At least 3 structured items per form should require transfer/application rather than recall.

## Candidate item families

These are conceptual families, **not yet psychometrically equivalent parallel items**:

- natural/artificial: E01 ↔ E02
- isotope identity: E03 ↔ E04
- irradiation/contamination: E06 ↔ E07/E08
- half-life definition/application: E12 ↔ E13; quantitative extension E14
- risk and half-life: E11 ↔ E16
- PET: E24 ↔ E38
- SPECT: E25 ↔ E39
- broader representation: E33 ↔ E35

## Recommended main-study administration after calibration

Randomize participants within the study design to:
- A-pre / B-post
- B-pre / A-post

If classroom cluster randomization is used for the intervention, form order can still be balanced within or across clusters as operationally feasible.

## Open breadth item

E40 can be asked pre and post because it is generative and scored by category breadth, but repeated administration may itself cue broader thinking. Pilot whether a parallel prompt (e.g. "Dove può incontrarsi o essere utile un radionuclide?") changes response style. Preserve the same coding framework.
